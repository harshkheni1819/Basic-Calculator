# Basic-Calculator
Discription of this calculator :-

    ~  Lets users input expressions using buttons or the keyboard.
    ~  Shows the full expression in the display.
    ~  Evaluates the expression using the correct mathematical order using BODMAS.
    ~  Supports extra features like brackets, percentage calculations, square root, and memory (optional).
    ~  Ensures a smooth and error-handled experience for users.
